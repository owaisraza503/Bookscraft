# Dependency & License Inventory

All dependencies utilized in Bookscraft have been audited for open-source compatibility:

| Component | License | Purpose |
| --------- | ------- | ------- |
| **Kotlin & Coroutines** | Apache-2.0 | Core programming language & asynchronous runtime |
| **AndroidX Jetpack & Compose** | Apache-2.0 | Modern declarative UI, Navigation, Lifecycle |
| **Material Components 3** | Apache-2.0 | Material You design system |
| **Apache PDFBox Android** | Apache-2.0 | ISO 32000-1 PDF annotation serialization & parsing |
| **AndroidX Room** | Apache-2.0 | Local SQLite database for recent documents |
| **JUnit 4 & Robolectric** | EPL-1.0 / MIT | Local JVM automated testing |

All dependencies are permissible under the project's overall **Apache-2.0** license.
