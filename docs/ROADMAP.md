# Bookscraft Feature Roadmap

## Phase 1: Core Engine & Embedded Annotations (Completed ✅)
- [x] Android `PdfRenderer` + Apache PDFBox Android integration.
- [x] Embedded PDF text highlights, sticky notes, underlines, strikethroughs, ink, and shapes.
- [x] Automated annotation round-trip verification unit tests.
- [x] Storage Access Framework (SAF) document opening and export.

## Phase 2: Reader Experience & Organization (Completed ✅)
- [x] Continuous scrolling and single-page modes.
- [x] Night / Inverted mode for low-light reading.
- [x] Full-text search with snippet preview navigation.
- [x] Page thumbnails grid drawer.
- [x] Page rotation and deletion.
- [x] AcroForm interactive form fields editor.

## Phase 3: Advanced Capabilities (Upcoming)
- [ ] On-device optical character recognition (OCR) for scanned PDFs using ML Kit.
- [ ] Multi-document merge & split wizard.
- [ ] Cryptographic X.509 digital certificate signing.
- [ ] Audio text-to-speech reading mode.
