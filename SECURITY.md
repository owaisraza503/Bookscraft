# Security Policy

## Supported Versions
Bookscraft actively maintains the latest released version for security patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Offline Privacy Guarantee
Bookscraft does not include internet networking libraries or background analytics services. User documents, annotations, and form data remain strictly on the local Android device and are never transmitted to third-party servers.

## Reporting a Vulnerability
If you discover a security vulnerability or document parser bug in Bookscraft, please do not disclose it publicly. Contact the maintainers privately or open a security advisory on GitHub. We aim to acknowledge and address reported vulnerabilities promptly.
